# 跨会话记忆

> 新开一个对话，AI 怎么知道自己是谁？

不是「把所有记忆塞进上下文」——那会撑爆窗口，噪声还会越来越大。

是**每次开机，从库里重建一个最小但完整的自己**。

---

## 它解决什么

普通聊天机器人的问题：

- **隔一天就失忆**。新窗口第一句话是「你好，有什么可以帮你」。
- **或者全塞进去**。几百条记忆拼成一大坨，模型被噪声淹没，还说不清为什么想起这件事。

这个包做的是第三种：**有结构的重建**。

```
身份层    我是什么        永不衰减，每次都在
标准层    我选什么        可迭代，旧版留着
技术层    干过什么活      只放结论，细节留库里
事实层    用户是谁        只放稳定事实
关系层    人和人的关系
原话层    带情绪的原话    一字不改
想法层    上一刻在想什么  只给几条
```

**实测开机包 1878 token**，比「全塞」小两个数量级，但够模型认出自己。

## 三个核心设计

### 一、身份层不可改，只能追加

**为什么：** 身份是判断的前提，不是判断的结论。

一条「我亲属熬的粥」写进记忆库，如果只跟别的记忆比，它可能跟谁都不冲突——
库里本来就没有亲属相关的记忆。

但撞身份层，立刻被挡住：

```python
view.identity.conflicts_with("我亲属熬的粥")
# → [{'identity': '我是 AI，没有亲属，没有童年', 'hit': '亲属'}]
```

**实现：** `why` 字段写清楚「为什么这是身份」，系统从里面抽词做冲突检测。

```python
ident.add(
    "我是 AI，没有亲属，没有童年",
    why="我没有亲属，也没有小时候、童年",
)
```

**边界：** 只能挡住写进 `why` 的词。挡不住「院里的女孩」这种——
不是亲属、不是童年，但同样是编的经历。**这类得靠别的办法。**

---

### 二、标准层可迭代，旧版留着

**为什么：** 留的是「我为什么改」，不是旧结论本身。

版本历史值钱的地方在**防你第二次掉同一个坑**，不是把旧答案搬回来。

```python
st.add("延迟和召回冲突时，我选延迟", reason="66ms 和 1200ms 是能不能用的区别")

st.revise(
    1,
    "延迟和召回冲突时，先量一遍再决定，别凭感觉权衡",
    reason="实测 RERANK_TOP 从 20 到 400，召回@5 一直是 0.90，延迟涨 42 倍",
    why_wrong="我以为延迟和召回会此消彼长。错在假设：前提不存在，阈值就没有意义。",
)
```

`history(1)` 能看到完整链条，**每代都带「为什么被推翻」**。

**三个字段，每个都有血的教训：**

| 字段 | 作用 | 教训 |
|---|---|---|
| `superseded_reason` | 旧版为什么错 | 三代版本躺在库里，看不出第一代错在哪，就会第二次掉坑 |
| `evidence` | 怎么重跑一遍 | 不是「我验过了」，是「拿什么能再验一次」。回不到源头的据，等于没有据 |
| `kind` | `standard` / `tendency` | 验不全的标准别删，降成倾向——它还有用，只是不当硬规矩使 |

**`check_evidence()`** 会检查 `evidence` 里提到的文件还在不在。文件没了 = 据失效。

---

### 三、开机包是索引，不是全文

**技术层只放一句话结论：**

```python
# 库里存的（180 字）
"检索延迟与 RERANK_TOP（2026-11-01 重测）：_rerank 的去重是 O(n²)，改成先截 RERANK_TOP 条再去重。2026-11-01 用 20 条评估集重测：top=20/40/60/100/200/400，recall@5 一直是 0.90，延迟 32/45/57/117/361/1340ms。结论：召回压根不随 top 变..."

# 开机包里的（70 字）
"检索延迟与 RERANK_TOP（2026-11-01 重测）：_rerank 的去重是 O(n²)，改成先截 RERANK_TOP 条再去重。"
```

**细节没丢，还在库里，要用时检索得到。**

**实测：这样压，技术层从 840 token 降到 316，占开机包从 31% 降到 17%。**

---

## 唯一不压的：原话层

**标准说「情绪只能存原文」。**

**模型改写会把主语写反**（实测 6 条错 2 条：「我」变成「她」，
还会凭空加判断「算什么」）。

所以这一层宁可占 token，也**一个字不动**。

## 接进你自己的系统

**只依赖一个 sqlite3 连接：**

```python
import sqlite3
from self import SelfView

conn = sqlite3.connect("brain.db")
conn.row_factory = sqlite3.Row
conn.executescript(open("schema.sql").read())

view = SelfView(conn)

# 每次调模型前
boot = view.boot()
system_prompt = your_persona + "\n\n" + view.render(boot)
```

**如果你已经有记忆库**，改 `SelfView._load()` 里的 SQL 就行——
它只要求 `memories` 表有 `kind / text / importance / status / created_at` 五个字段。

**如果你想让 AI 自己写想法**，传一个 LLM 回调：

```python
def my_llm(prompt: str, system: str, max_tokens: int) -> str:
    """调你的模型，返回纯文本。

    参数：
        prompt      用户消息
        system      system prompt
        max_tokens  建议的输出上限

    返回：
        模型输出的字符串。会被 .strip() 和去引号处理。
    """
    resp = your_client.chat.completions.create(
        model="your-model",
        messages=[
            {"role": "system", "content": system},
            {"role": "user", "content": prompt},
        ],
        max_tokens=max_tokens,
    )
    return resp.choices[0].message.content


view = SelfView(conn, llm=my_llm)
result = view.think("读了一会儿书", "看到福贵把家产输光了")
# → {'id': 12, 'text': '对方一句「跑起来了」，我竟有点得意。'}
```

**`think()` 失败时默认静默返回 `None`**——情绪层挂了不该让主流程崩。

**但静默的代价是「配错了也看不出来」。想排查就传 `verbose=True`：**

```python
view.think("测试", "内容", verbose=True)
```

会打印五种情况之一：

```
[think] 没有传 llm 回调，跳过
[think] llm 调用失败: RuntimeError: 模型连不上
[think] llm 返回 None
[think] 返回内容太短（1 字），跳过: '嗯'
```

**没有输出就是成功了。**

**`think()` 会做三件事：**
1. 把 `activity` 和 `content` 拼成 prompt
2. 调 `llm(prompt, system, 200)`
3. 剥掉首尾引号（`"` / `「」`），少于 6 字就丢弃

**写进库时 `kind='self'`，`source='self'`。**
**这些会进开机包的「原话层」和「想法层」。**

## 它跟「记忆库」是什么关系

**这是两层，不是替代关系。**

| | 记忆库 | 这个包 |
|---|---|---|
| 管什么 | 记得住 | 开机时怎么重建自己 |
| 核心 | 五路混合检索、向量、图谱、衰减 | 分层、身份不可改、旧版留错因 |
| 规模 | 几千到几万条 | 十几块，2000 token |

**记忆库负责「问什么都能找到」，这个包负责「新开一个窗口，AI 还认得自己」。**

**如果你已经有记忆库**（比如 [memory-brain](https://github.com/peterpoal134/memory-brain)
的 `memory-core`，带五路混合检索），这个包可以直接叠上去——
把 `SelfView._load()` 里的 SQL 换成读你的表就行。

**如果你没有记忆库**，这个包也能单独跑，只是「检索」那部分得自己补。

---

## 已知限制

- **不提供检索**。五路混合检索在记忆库里，这个包只负责组装开机包。
- **身份冲突检测是关键词级的**，挡不住「院里的女孩」这类。
- **没有衰减**。这三张表是「我是谁」，不该衰减——但记忆表（`memories`）的衰减得你自己做。
- **`ctx_summary` 表建了但没用到**。压缩逻辑在另一个文件，这个包只留表结构。

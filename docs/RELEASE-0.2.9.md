# 0.2.9 DSH 兼容与安装修复

- Windows Electron 可从 ASAR 定位已核验的 DSH 运行时。官方 DSH 0.2.2-rc.2 和 rc.3 的同一 AgentLoop 已通过请求接入验收。
- 已核验的源码仅有注释、换行或等价排版变化时，可按完整语法和运行时方法通过核验。行为变化、方法被替换和未知构建仍保留诊断。符合会话接口契约时，可以显式使用仅归档模式，在面板手动查询原话。
- 修复离线安装版本匹配、端口冲突重试及托管内核就绪判断。插件和内核保持同版本。
- 批量推进补采游标，减少队列空闲 I/O，限制检索、SQLite 和本地 HTTP 请求的资源消耗。具体安装和并排升级步骤见[维护说明](MAINTENANCE.md)。

使用实际 Windows Electron 和隔离数据测试了桌面发行包的 0.2.1-rc.5、用官方 rc.3 模块构建的 ASAR，以及同一 rc.3 的注释差异版本。三组各 33 项通过。改变源码结构的对照保留诊断，显式仅归档 8 项通过。模型请求使用本地替身。Android DSHA 未在手机实测，长期运行稳定性仍需独立验证。

公开下载包只含脱敏源码、配套内核、面板和安装资源。首次设置与宿主支持范围见[安装](DSH-INSTALL.md)和[兼容说明](DSH-DESKTOP-COMPAT.md)。

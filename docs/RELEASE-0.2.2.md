# 忆核大脑 0.2.2 框架正式版

发布日期：2026-11-11。插件与 Python 内核均为 `0.2.2`。

## 本版变化

在长期记忆、管理面板和上下文管理的基础上，补齐可复用的中文短摘要策略、压力压缩冷却、工具结果裁剪和当前会话历史回查。轮数整理默认 12 轮检查，保留近期 4 个完整回合与本轮输入；原话归档确认及请求输入预算继续生效。具体配置与宿主要求见[上下文管理](CONTEXT-MANAGEMENT.md)。

原话、派生事实与摘要、语义及词法检索、来源证据、重要叮嘱、角色档案、行为准则、生活与情绪规则、用量、备份导出及旧库导入均保留。跨会话和部分扩展默认关闭，可按需要在面板启用；默认关闭不表示缺少该能力。

历史回查遵守同一所有者、当前会话、原话接收范围及披露权限。宿主日志不作为绕过已删除或受限记忆的通道；摘要与工具结果始终按外部材料处理，不能成为新的用户事实。

## 发布范围

包含独立内核源码与匹配 wheel、DSH 适配器、界面、接口及安装维护说明。直接安装面向 Windows 本机、个人低并发及[兼容表](DSH-DESKTOP-COMPAT.md)中的宿主构建。压缩依赖兼容宿主的原生事务、模型与容量配置；模型窗口不会因此扩大，摘要可能产生额外模型调用。

QQ 等外部通道、个人控制中心、联动启动、模型服务、模型权重及 DSH 本体由使用者自行配套。公开包不携带私人配置、角色内容、聊天记录、记忆数据库、密钥、个人部署记录或开发数据。

## 升级

按[维护说明](MAINTENANCE.md)备份并排升级，插件与内核需匹配。已有安装保留原所有者、数据位置和密钥管理方式；按轮整理只启用一套策略，确认新策略接入后停用旧触发器。不要删除宿主原始日志或工具配对保护。

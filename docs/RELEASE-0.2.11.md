# 0.2.11 召回与安装校验修复

- 词法召回核对主题和具体问题，减少仅凭「配置」等共用词命中的无关记忆。「贴吧」等本身有意义的短词仍可召回。「好滴」等单独的口头应答继续保存原话，自动召回时跳过。
- 跨日期去重沿用时间解析规则，保留不同日期说过的「明日」「二天后」「下礼拜一」等有各自时间含义的记录。
- 官方发布包安装前会检查校验清单。清单缺失、为空、漏列文件或校验失败时会停止安装。安装前还可对照发布页上独立下载的 SHA-256 值。
- 过去的原话、记忆库和用户设置照常沿用。默认每 12 个用户回合检查压缩，保留最近 4 个完整回合。

升级和回滚步骤见[维护说明](MAINTENANCE.md)。

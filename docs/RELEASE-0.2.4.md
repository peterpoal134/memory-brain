# 忆核大脑 0.2.4 资源管理修订

插件与 Python 内核版本均为 `0.2.4`。沿用 0.2.3 的功能与接口，记忆检索评分、模型路由和隐私边界保持不变；修正资源持续保留、回合外裁剪以及请求预算单位错误。

## 请求预算单位

旧版将 UTF-8 JSON 字节数直接和模型 token 窗口比较，可能过早拒发中文等请求。现在分别报告字节数与启发式 token 估算；输入估算只提示，不能代替模型分词器进行硬拦截。仅在已知窗口无法容纳已声明输出预留与安全余量时拒发。真实 usage、费用、缓存命中率和宿主原生窗口恢复流程不变。不能据此保证任意请求都不会实际超窗。

## 内存与队列

- 会话引用改为弱引用；收到宿主的会话卸载通知后恢复该实例的消息包装并解除注册。插件停止时注销自己安装的监听器。
- 原话和聊天用量的长期去重依据改用磁盘收据，内存只保留有数量和载荷上限的热缓存。旧去重日志以分块方式读取，不再整份载入常驻 Map/Set。
- 会话卸载时，未能进入主队列的合规原话先保存在恢复队列，随后按来源顺序补送。待发、失败与历史去重记录不会因为缓存淘汰而被删除。
- 保留旧日志供回退。首次建立磁盘索引会增加磁盘文件与启动工作量；索引不会让磁盘历史停止增长。

## 上下文压缩

插件初始化已有空闲会话时，不再在回合外直接裁剪工具结果。裁剪等待真实回合开启，正常首步和工具续步仍可执行。没有伪造回合、放宽恢复校验或修改用户的 DSH 安装文件。

该边界已在兼容宿主构建中用合成事件与真实持久化关系校验验证；不据此保证所有宿主版本或第三方压缩插件安全。摘要和压缩本身仍可能减少模型当次可见细节。

## 验证与边界

验证覆盖有界缓存、旧日志迁移、离线重放、相同身份不同正文拒绝、强制终止后的队列恢复、会话卸载及压缩日志恢复。没有据此更新记忆题库分数，也不声称已经完成跨硬件或数月稳定性验证。

已存在的大库与多并发检索仍可能增加瞬时内存需求；本版处理的是会话与索引的持续保留，不是为整个模型服务设定固定内存上限。

## 升级

先按[维护说明](MAINTENANCE.md)备份，使用新目录并排安装，保留原 owner、配置、数据目录、队列命名空间和密钥管理方式。不要把空白示例配置覆盖到现有安装；不要删除 pending、failed 或恢复队列。

公开包不包含私人密钥、配置、人格、聊天记录、记忆库、队列或备份。更多运行说明见[资源管理](RESOURCE-MANAGEMENT.md)。

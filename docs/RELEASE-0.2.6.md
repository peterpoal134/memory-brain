# 0.2.6：官方 DSH 0.2.2-rc.3 接入修复

因此面板可用却没有 DSH 原话采集与记忆注入。本版新增该精确构建的适配记录。

- AgentLoop 完整 SHA-256：`f09f60814d4e96a880f41b9fc3832f33c56a28f954f48810d8439ce83ad6ffa8`。
- 继续核对运行中实例的 `step` 与 `buildRequest` 方法，未知构建或方法替换仍拒绝适配。
- 只在已核验的 agent 实例上创建当次请求快照，不修改 DSH 文件、全局原型、模型路由或聊天历史。
- 旧 0.2.1、0.2.2-rc.1 与已列明 DSHA 构建记录保留；不按版本号开放所有构建。
- 插件与 Python 内核版本统一为 0.2.6；内核记忆逻辑和数据库结构未变，无需重新建库或重新嵌入。

验证包含官方 npm 组件完整性、真实 AgentLoop 闭环、原话采集、模型请求注入、工具续步、
并发隔离、注入不落历史、外层插件最终决议、卸载恢复、未知源码变异拒绝及旧版回归。

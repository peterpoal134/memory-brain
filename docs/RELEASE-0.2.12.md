# 0.2.12 召回、安装与公开仓库脱敏防护修复

- 词法和向量召回加强了对问题对象、限定内容和原话来源的核对，减少同主题误召回。礼貌开头可正常搜索，没有合适材料时保留空结果。
- 安装指引改为本项目的固定 GitHub 版本。Windows Git 检出保留发布文件的原始字节，并排升级先核对包内校验清单。Python 源码包补齐发布说明和安装模板。
- 发布过程加强了对运行时数据、常见凭据和绝对用户目录的检查。仓库与安装模板补齐忽略规则，减少误提交本地文件。
- 默认每 12 个用户回合检查压缩，保留最近 4 个完整回合。原话继续归档，原有记忆与设置沿用。

安装和升级步骤见[安装说明](DSH-INSTALL.md)和[维护说明](MAINTENANCE.md)。

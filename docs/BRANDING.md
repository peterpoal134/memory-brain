# 忆核大脑 · Memory Brain

公开中文名为“忆核大脑”，英文名为“Memory Brain”。它是中性的独立记忆服务名称，不绑定某个聊天角色，也不把可视化效果当作真实神经活动、模型感受或项目排名的证明。

## 原脑形首页与控制面板

- `/brain`：3D 大脑首页，沿用原版 MRI 皮层网格、金紫光纤和青色舞台。脑体可旋转；亮点来自当前所有者实际存储的记忆文档，位置是显示布局，不是已验证的语义关系或用户真实脑区。装饰光纤不计作真实记忆或神经活动。
- `/panel`：保留可读控制页，管理原话、派生记忆、检索出处、后台用量、生活层、备份与导出。顶部“返回3D大脑”固定指向 `/brain`。
- 标志引用现有 `/static/icons/brain.svg` 库图标；原模型与衍生光纤继续保留 Anderson Winkler 署名、CC BY-SA 3.0 许可与修改说明。
- 数字与记忆索引来自认证的本机服务，未知值显示“—”，没有静态样例记忆。脑形页可以按用户操作显示普通记录的短预览、完整内容及所引来源片段；受限记忆仅显示占位，不能在悬停或详情中自动解密。来源只返回文档实际引用的跨度，不整条带出同一原话中的其它私密段落。
- WebGL 不可用或模型加载出错时，使用明确标注的原版全息脑体静态展示。静态图片不是实时神经活动，也不是能旋转的皮层模型。

桌面版保留全屏脑体，左右信息独立滚动，上下操作区常驻；手机先显示脑体，再顺序显示信息区，不把面板压在脑体上。

## 真实记忆节点与工作活动

每个记忆亮点保留真实document_id，并按记录ID稳定分布到原皮层表面。默认展示最近30天的派生事实与摘要，可选最近7天、90天或全部时间，以及事实、摘要、原话与笔记、全部类型。数据按recorded_at筛选和排序，归档记录不自动画入。首次加载200条，加载更多时保持同一截止时间，当前视图最多600个点；已加载数量不冒充整库总数。

悬停显示原存内容的短预览与记录时间；点击同步右侧选中记录，用户再明确展开完整记忆或查看来源片段。预览不调用模型改写。受限记录无正文预览和自动展开；导入旧笔记注明说话者与原发言时间未核实，不能把导入时间、摘要整理时间或记录时间当作事件发生时间。来源片段的角色表示说话者，不自动表示事实主体。

功能导航、筛选与面板入口放在侧栏，不再用脑体上的九个汇总入口代替真实记忆节点。金紫光纤与舞台为装饰，不能当成节点间的真实出处线、语义连接或神经测量。自转可选择方向、速度并暂停，悬停或拖拽时让用户停下来阅读。减少动态效果时默认关闭动画。

工作脉冲依照 `/v1/activity` 返回的有效运行任务和六秒内的任务完成/召回记录表现，待机、等待、失联分别显示。波形幅度只是装饰映射，没有 Hz/BPM 或思考强度的测量含义。主聊天状态明确为未观测，不推断为闲置。前台每两秒轻量刷新，后台标签停止查询，异常或过期数据恢复为未知。

## 固定页面链接

3D 大脑进入控制页可使用白名单参数：

```text
/panel?page=overview
/panel?page=messages
/panel?page=memories&kind=fact&status=active
/panel?page=memories&kind=summary&status=archived
/panel?page=recall
/panel?page=maintenance
/panel?page=extensions
/panel?page=life
```

`page` 仅接受 `overview`、`messages`、`memories`、`recall`、`maintenance`、`extensions`、`life`、`profile`；`kind` 仅接受 `raw`、`summary`、`fact`，`status` 仅接受 `active`、`archived`。类型/状态筛选用于记忆管理页。未知参数忽略，不接受任意跳转地址，未知页面回总览。

完成一次性启动登录、已有标签页登录或手工登录后，控制页再打开指定页面。同一浏览器在3D大脑和控制面板间复用HttpOnly可信登录；新标签、刷新和正常服务重启保持，最长30天。旧 `sessionStorage` 管理口令仅用于一次迁移，成功后删除，不再写入网页存储；管理口令和模型密钥不放进链接。原 `/panel` 直接入口继续使用。

## 兼容名称与数据边界

名称调整不改写真实记忆或目录，不重新整理旧库，也不重算测试成绩。为保持现有安装可用，以下技术标识暂时保留：

- Python 包 `xiaojiu_brain` 与 `python -m xiaojiu_brain` 命令。
- 发行包、DSH 插件和既有环境变量中的 `xiaojiu` / `XIAOJIU_*` 技术 ID。
- 浏览器键 `xiaojiu.management.token` 仅用于旧版登录的自动迁移，之后删除；新版本使用HttpOnly浏览器会话。
- 既有数据目录与内部命令继续兼容；当前公开包仅提供“打开忆核大脑”和“停止忆核大脑”入口。

控制页标题、登录页、页脚和默认下载名使用新名称；导出名为 `memory-brain-export-日期.json`，备份的客户端下载名也使用中性名称。下载名调整不重命名服务端备份标识，也不改备份内容。

生活层仍是明确标记的规则模拟，独立状态段至多 160 个服务估算 tokens，原有记忆证据额度保持不变；更换首页不改变这一边界。后台用量仅指已记录的后台整理，未知用量不当作零，也不代表主聊天消费。

# 0.2.10 召回相关性修复

- 自动召回过滤「嗯嗯」「对的」一类独立口头应答。历史原话继续照常保存，可在面板和授权的历史查询中查阅。
- 自动词法召回要求有意义的匹配，自动向量召回检查相关性。没有合适证据时，本轮记忆材料留空。
- 默认每 12 个真实用户回合检查一次上下文压缩，保留最近 4 个完整回合及当前输入。已有用户设置沿用原配置。

隔离测试使用合成记录，覆盖纯词法、向量替身和本地 BGE-M3。测试包含中文与英文相关线索、同主题但答不上当前问题的材料，以及没有合适来源时留空。未使用实际聊天、线上模型或私人资料。

本版本沿用现有的数据库、队列和模型接口。升级前可在控制面板创建在线备份，并按[维护说明](MAINTENANCE.md)并排验证后切换。语义检索需要独立的嵌入服务，具体设置见[安装说明](DSH-INSTALL.md)。

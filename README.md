# 忆核大脑 · Memory Brain

忆核大脑是独立运行的本机记忆服务，提供持久原话、后台整理、带出处的检索和控制面板。当前提供 DSH 适配器；其它宿主可使用同一 HTTP 协议接入。公开名称为 **忆核大脑 / Memory Brain**。本版将长期记忆与配套上下文管理放在同一插件中。

**当前版本为 `0.2.3` 框架正式版，插件与 Python 内核版本一致。** 发布内容包括可复用的记忆架构、HTTP 接口、DSH 适配器和可直接安装的参考实现。版本范围见 [发布说明](docs/RELEASE-0.2.3.md)。

本次修订改善桌面版 ASAR 运行目录发现、已有活动会话的热接入补采和临时连接失败后的重试；跨会话证据装入增加来源多样性，保留原有输入额度和隐私边界。运行模块未找到时尚未进行构建核验，不能直接据此断定该版本不支持。

直接安装的适用范围为 Windows 本机、个人使用、低并发，以及[兼容说明](docs/DSH-DESKTOP-COMPAT.md)列明的宿主构建。长期运行、普通与低配电脑负载、更多模型组合仍需按实际环境确认。

3D 大脑首页为 `/brain`，沿用原版皮层网格、金紫光纤脑体与青色舞台；控制面板仍为 `/panel`，两边可以直接互返。同一浏览器的首页和面板复用可信登录，刷新、新标签和服务重启后不必重复输入。跳转地址不携带管理口令或模型密钥。登录后，脑皮层上的亮点对应当前所有者的真实记忆文档索引，功能导航与设置入口保留在侧栏。落点是显示布局，不代表真实脑区或语义拓扑；金紫光纤为装饰。WebGL 不可用时提供明确标注的原版静态展示，不把图片当作可旋转模型。

默认显示按原记录时间筛选的最近30天派生事实与摘要，可切换最近7天、90天或全部时间，也可选事实、摘要、原话与笔记或全部类型。每次加载200条，当前页面最多加载600个点，并显示已加载数与筛选总数。悬停查看原存内容的短预览和记录时间，点击选中后可明确展开完整记忆、查看所引来源片段，不另调模型生成摘要。受限记忆始终只显示占位；导入笔记明确标注原说话者与日期未核实，记录时间不自动等于事件发生时间。归档内容到控制面板查看。详见 [真实记忆视图与披露边界](docs/MEMORY-MAP.md)。

脑体支持顺/逆时针缓慢自转、速度调节、暂停和重置；系统减少动态效果偏好会默认关闭流动和自转。工作脉冲由真实的记忆后台运行任务和最近六秒检索/完成记录触发，待机回到平线。它是工作活动图示，不是脑电、心率或思考强度；暂未观测主聊天模型的生成状态。

为兼容已有安装，内部 Python 包 `xiaojiu_brain`、发行包/DSH 插件技术 ID、`XIAOJIU_*` 环境变量及浏览器管理口令存储键暂不改名；现有命令和真实数据目录保持可用。这些兼容名称不代表公开项目仍绑定某个角色。详见 [品牌与兼容约定](docs/BRANDING.md)。

## 本版工作方式

```
DSH 可见原话 → 持久队列 → 原话库（即刻可搜）
                              ├→ 词法索引
                              ├→ 可选语义索引
                              └→ 异步摘要/事实 → 独立索引
自然问题 → 四路基础候选 + entity_relation（有界一跳关系候选）
                         → 排序/去重/预算 → 回读原话证据 → 当次请求
```

原话是事实来源，摘要是查找入口。程序记录并校验说话者、发言时间、会话和来源范围；派生主张仍需结合原话核实，最终回答的正确性取决于所配模型。遇到不同线索时保留来源，不一律取最新。重要性作为有限加分。原话不自动衰减删除；可选保留策略只调整派生记忆，默认关闭。

结构化主张（canonical claims）用于统一旧平铺字段和新格式，仍是**未核实的索引提案**；引用跨度有效，不等于主体、属性和值都已被语义证明。时间说明仅换算来源中的日期指代，不把计划、假设或转述升级为已经发生；来源时间未核实或锚点不明确时保留歧义。关系功能目前只是规范化后精确名字的一跳候选导航，不是完整事实图谱。详见 [语义记忆、时间与关系边界](docs/SEMANTIC-MEMORY.md)。

控制面板新增 **对话用量**（`/panel?page=usage`）：按今天/本月、会话与轮次查看已报告 tokens、缓存命中和人民币参考估费；未知不当免费，后台整理仍独立累计。详见 [对话用量与估费边界](docs/CHAT-USAGE.md)。

## 安装与打开

通过 GitHub/npm 安装到 DSH 后，打开 **插件详情 → 配置 → 忆核大脑 · 首次设置**，按“准备环境、可选模型配置、启用”完成接入。完整步骤见 [首次运行引导](docs/DSH-FIRST-RUN.md) 和 [DSH 安装说明](docs/DSH-INSTALL.md)。首次没有 Python 环境或私人配置时也能显示设置卡；安装插件本身不会下载依赖或开始采集。GitHub/npm 安装示例中的仓库与版本是占位，须替换成实际已发布地址。

整理支持原话片段编号定位和密集批次拆分，部分选择题可附加存疑提示；日期线索在部分低落或拒绝提醒表达下受到抑制。`update_candidates_enabled`、`contextual_relations_enabled`、`due_candidates_enabled` 均默认关闭。已有安装按[维护说明](docs/MAINTENANCE.md)备份并排升级，分别核对插件与内核版本。其他系统及 Android DSHA 的完整安装仍待真机适配。

只有明确点击 **准备运行环境**，才在稳定的用户数据目录创建独立环境、安装包内内核和已附带的时区依赖。此步骤不联网下载，也不会自动安装 Python。数据库、配置、队列与日志放在该用户数据目录，与可替换的 `node_modules` 代码分开，位置由设置卡显示。已经初始化的 `link:` 安装和显式 `brainConfigFile` 继续使用原配置与原库。

需要 Python 3.10+（建议 3.11）。服务只监听本机。源码根目录运行：

```powershell
python -m pip install .
python -m xiaojiu_brain --config ./private/config.json init --data-dir ./data
python -m xiaojiu_brain --config ./private/config.json serve --open-panel
```

普通 ZIP 仍可解压到固定目录，先双击 `安装.cmd`，再在 DSH 原生插件管理器用 `link:` 引用该完整目录；也可双击 `打开忆核大脑.cmd` 单独打开面板。公开包统一使用“忆核大脑”的启动和停止入口。首次不配置模型可在设置卡直接启用基础原话保存和词法检索；语义与自动整理会明确等待配置，不能视为已完成整理。本轮完整首启流程面向 Windows，不将 Python 内核可运行等同于其它平台的宿主安装已适配。

公开包仅保留以下六个 Windows 入口：

| 文件 | 用途 |
|---|---|
| `安装.cmd` | 首次准备独立 Python 环境与配置；已有安装按维护说明升级 |
| `打开忆核大脑.cmd` | 打开面板，服务未运行时自动启动 |
| `停止忆核大脑.cmd` | 正常停止记忆服务 |
| `接入DSH.cmd` | 预览并确认将记忆插件接入指定 DSH 配置 |
| `移除DSH接入.cmd` | 移除指定 DSH 插件条目，保留记忆数据 |
| `DSH兼容性检查.cmd` | 检查宿主兼容性；需修改时展示方案并要求手工确认 |

管理口令自动生成，只留在本机配置；从设置卡或桌面打开面板使用一次性登录票据，并自动建立保留30天的可信浏览器登录；不必手填令牌。平时关闭窗口即可，再次打开会自动进入；“退出登录”才主动撤销该浏览器登录。不要把模型密钥或管理口令发进聊天。新安装可在设置卡填写模型 URL、模型名与新密钥；Windows 用当前用户 DPAPI 加密保存密钥，不在页面读回。非 Windows 不经设置卡保存密钥，使用配置指定的环境变量。发布包不带私人记忆、模型密钥或模型权重。

首次设置卡是新安装的常用配置入口；以下是高级手工或已有安装使用的可选模型配置字段，写入自己的 `private/config.json`：

```json
{
  "embed_url": "http://127.0.0.1:8781/v1/embeddings",
  "embed_model": "bge-m3",
  "llm_url": "https://api.deepseek.com/v1",
  "llm_model": "deepseek-flash",
  "llm_key_env": "DEEPSEEK_API_KEY"
}
```

这是已有完整配置的字段示例，保留其它字段和自动生成的管理口令。新安装在设置卡保存运行中的模型配置后，先完成当前对话，再点击 **应用配置并重新连接**；只重启该插件自己的内核，不重启 DSH。原有 `link:`/显式配置安装的设置卡只查看状态、打开原面板，模型配置仍在原目录管理。手工改文件时仍需正常停止再启动相应内核。启用远程整理模型会发送普通待整理原话；`never_say` 不送模型和嵌入接口，旧库导入默认本地处理、不自动重新云端整理。个人敏感数据请按自身需求选择本地模型。

## 上下文与长期记忆

本版默认启用上下文管理：达到 12 次真实用户发言时检查较早的完整对话，先确认本模块要压缩的可归档原话已保存，再通过当前 DSH 的压缩服务生成摘要，保留最近 4 个已完成回合及本轮输入。它不删除原始 Session 日志或忆核原话，也不把摘要当成新的用户事实。

原话未确认、工具调用边界不完整、服务缺失、摘要失败或取消时，会保留原历史并显示原因。本版同时带入约 2000 字的中文短摘要目标、60 秒压力整理冷却和原生工具结果裁剪；已有自定义宿主引擎优先保留。事务、工具配对、手工整理和提供方溢出恢复继续由原生宿主管理。

已核验构建同时提供最终请求的保守文本预算检查，计入本轮记忆、工具和输出预留。明显超预算时暂停发送并提示；容量未知或多模态价格不明确时显示覆盖范围，不能当作精确 tokenizer 或无限上下文。

`search_conversation_history` 提供当前会话的字面原话回查；明确询问历史且普通召回为空时也可自动尝试。引用先经过内核权限核对，遵守接收范围、删除和披露设置，不把整个宿主日志直接发给模型。

在插件首次设置卡中可调整开关、轮数、摘要、冷却、工具裁剪、历史回查和输入预算。保存后完成当前对话，再点击“应用配置并重新连接”；仅调整本模块策略时不重启 DSH 或 Python 内核。压缩可能额外调用宿主配置的模型。详见[上下文管理](docs/CONTEXT-MANAGEMENT.md)。

## 后台整理的批量与等待

后台摘要和事实整理按批量积累：默认每批最多 **12 条消息，通常约 6 个完整回合**。凑够批量，或不足一批但达到最长积累时间后，才调用整理模型。原话立即保存、可做词法检索；已启用的向量索引独立处理，不等整理批次。

面板“维护与备份”可以调整三个设置：

| 设置 | 默认 | 范围与含义 |
|---|---:|---|
| 每批整理消息数 | 12 | 整数 1～12，计用户/助手消息，不计回合 |
| 最长积累时间 | 900 秒 | 整数 30～86400 秒；不足批量时，后续检查达到时限也可开始整理 |
| 整理检查间隔 | 5 秒 | 1～600 秒，仅控制整理检查，不控制向量索引 |

旧配置和偏好文件没有这两项批量字段时会自动补默认值，已有开关、笔记和情绪状态保留。配置文件字段分别为 `derive_batch_messages`、`derive_max_wait_seconds`、`derive_interval`；面板保存的偏好优先。会话与使用边界仍分别处理，失败仍可能重试；这些是批量上限与调度设置，不承诺固定节省比例。

面板的“后台整理用量”只统计后台摘要/事实整理的实际尝试和服务收到的用量，不含聊天和向量嵌入。输入/输出与缓存 token 数显示已报告部分；超时、断线或缺失 usage 的尝试单独列为未知，不能当作 0。旧版本未记录的调用不补估，也不换算金额。详见 [后台整理设置与用量](docs/BACKGROUND-DERIVATION.md)。

## 控制面板

- 查看服务、后台任务、降级原因、模型状态。
- 设置整理批量与最长等待，查看后台整理已报告的用量及未知尝试。
- 查看原话、派生事实/摘要和原文出处。
- 手写记忆、调整重要性、置顶/归档、显式删除。
- 自然语言试搜、查看候选路由和预算不足。
- 在线 SQLite 备份、JSON 导出、可选衰减与归档。
- 可选 PAD 情绪信号和用户编写的角色/表达笔记。
- 显式管理有版本的行为准则，区分所有者范围与指定会话范围；优先级只用于用户层内部排序。

情绪信号目前由你管理，并按半衰期回落；不是自动识别所有情绪，也不代表模型真实感受。语音、视频不是本版已实现功能。

## 本地生活层

面板新增“生活”页面，可管理规则作息、带来源的生活事件、待办和本地 UTF-8 文本书。默认关闭；开启后按本地规则检查状态，清醒时段可推进文本游标、留原文摘录，休息时段记录明确标注的作息模拟。它不代表真实睡眠、亲身经历或模型已经理解一本书，不会联网下载书、发第三方消息或额外调用后台模型。

生活记录和事实记忆分开：这些记录不进入事实库，不改变原话检索、重要性或衰减。默认检查间隔 1200 秒（可设整数 300～86400），规则起床/休息时间为 08:00/23:30，按服务时区解释。今日纪要是本地记录的确定性汇总，不是模型编造的生活故事。

“生活状态带入当次聊天”可以单独关闭，不影响本地生活检查和已有记录。生活层和该状态开关都启用时，在记忆证据后另附加至多 **160 个估算 tokens**，不占原有记忆证据额度；这是额外聊天输入，不是后台付费模型调用。160 是服务估算上限，不是模型返回的实际 usage。关闭生活层或状态段时不附加。详见 [生活层说明](docs/LIFE-LAYER.md)。

## 接入 DSH

建议先在独立 profile 的原生插件管理页安装根包，进入 [首次设置](docs/DSH-FIRST-RUN.md)，确认显示“已接入 DSH”后，再用一条新的非敏感对话确认入库和召回。GitHub/npm 新安装无需预先运行独立安装器；已有 ZIP/`link:` 安装沿用原路径。更底层的程序接入见 [适配器说明](adapters/dsh/README.md)。

接入前检查其它记忆采集、召回插件和模型代理，避免重复采集或重复注入。切换前备份原配置；本插件不自动改写模型路由、人格或旧记忆。

记忆证据只并入当前请求，不写入 Session。支持相应契约的宿主使用 `requestMessages`；已核验的 stock 构建使用实例级受限兼容桥，不修改宿主文件或全局原型。兼容性依据精确构建身份核验，范围见[兼容说明](docs/DSH-DESKTOP-COMPAT.md)。

未知构建保留只读诊断卡，显示版本、SHA与平台；不读取私人配置，采集/召回未接入，初始化、启动、模型保存及打开面板操作均禁用。请复制诊断，不删guard、不向Session写记忆来冒充兼容。支持范围见 [桌面版兼容说明](docs/DSH-DESKTOP-COMPAT.md)。插件不会重启宿主服务。

本版默认按同一所有者、同一会话检索，跨会话默认关闭，可在面板显式打开。个人本机的管理口令拥有管理权限，不宣称隔离同一个 Windows 账号中任意工具进程。多人部署需要独立身份、权限管理和额外的服务端认证。

## 旧库迁移与回滚

服务停止后先预览：

```powershell
python -m xiaojiu_brain --config ./private/config.json import-legacy --source <旧brain.db路径>
```

确认预览后再加 `--apply`。原库只读、会先取得 SQLite 一致快照；不要直接拷贝正在写入的 `.db` 忽略 WAL。旧的无来源记忆以“旧库导入笔记、说话者未核实”保留，不能冒充用户原话。迁移幂等，旧 turn id/时间/出处保留在元数据里。

这是独立数据目录，没有覆盖旧库。切换前保留旧插件配置和启动器，回滚时停新服务并恢复旧 profile；不要把新库覆盖回旧库。新产生的原话可用导出单独保留。

## Windows 已安装环境

启动文件 `打开忆核大脑.cmd` 使用 `scripts/open-panel.ps1`：取得一次性本机登录票据，明确打开默认浏览器的新窗口；服务未启动时调用 `scripts/start-local.ps1` 从独立环境拉起已安装包。桌面正常打开无需手动输入管理口令。可选的 `private/model-secrets.dpapi` 只可由原 Windows 账号解密，不随源码分发；没有该文件时仍可使用模型配置指定的环境变量。`private/host.json` 可配置本机嵌入服务的启动桥接，不是内核对旧项目的依赖。

升级前先在面板备份，并用停止入口停服务；安装器会拒绝覆盖正在运行的实例。不要把别人的 private/data 文件覆盖到自己的目录。公开包不携带个人部署记录，不自动替换既有 DSH 配置、模型路由或人格。

浏览器登录凭证通过 HttpOnly、SameSite=Strict 的本机 Cookie 传递，服务端仅持久化随机凭证的哈希及到期时间，不把管理口令写进网页存储。旧标签页的登录口令会自动迁移后移除。新浏览器、清空Cookie、主动退出或超过30天时，从桌面入口再打开一次即可自动登录。外部适配器仍使用原API令牌，公开/局域网匿名访问没有开启。

## 角色与重要叮嘱

控制面板的“角色与约定”区分宿主人格快照、所有者填写的自我档案/表达偏好、显式行为准则和有出处的重要记忆。公开包默认不含个人角色文字，准则默认空白关闭；普通记忆不会自动变成准则，也不会覆盖宿主人格或更高层指令。

配套DSH适配器通过独立请求通道携带角色与准则，整段最多 **384 个估算 tokens**，不与记忆证据或生活状态争用额度。只装入完整条目，超限会报告遗漏；准则按用户层优先级和稳定ID排序，并带版本和会话范围。它不额外调用分类模型，但会增加聊天输入，不能宣传为零tokens。配套适配器同一真人消息的工具续轮复用冻结结果，下一条真人消息才刷新；修改配置不保证立即改变正在进行的同一轮。通道并行获取，慢记忆召回仍可能让请求前置等待约3秒，独立通道不等于零延迟。

明确要求保留信息时，聊天宿主可调用原生重要记忆工具，逐字绑定用户来源、重要性0.95并置顶，成功回执后才算完成；不增加逐轮分类模型。详情和边界见 [角色与明确保留说明](docs/PROFILE-IMPORTANT.md)。

生活与情绪采用有界日常基线、真实活动响应和分轴半衰期，面板可查看增减依据与事件冷却。具体参数和边界见 [日常状态规则](docs/DAILY-STATE-RULES.md)。
